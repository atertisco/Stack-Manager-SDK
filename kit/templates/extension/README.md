# MyExtension

A Stack Manager extension.

1. Change `extension.json`: the description, the capabilities that the extension uses, and the version.
2. Change `Extension.cs`.
3. Run `.\build.ps1`. The package is written to `dist\`.
4. In Stack Manager open Extensions, select Install from file and select the package.

See the documentation in the SDK kit, `docs\01-getting-started.md`.
